Gambar catatan memperlihatkan daftar dan kontrol; permukaan editor teks terpisah tidak ikut tertangkap. Pilihan Glass Lite pada gambar Pengaturan memakai Solid fallback, sehingga gambar tersebut tidak menunjukkan blur aktif.
