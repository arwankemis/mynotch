# Changelog

## 0.0.1 alpha — 26 Oktober 2026

- Paket pertama dengan nama mynotch, executable mynotch.exe, portable Windows x64.
- Musik, lirik/visualizer, kalender Indonesia 2026, Reminder, dan Clipboard opsional.
- Pengaturan dirombak: navigasi kiri, kontrol konsisten di kanan, label singkat dan penjelasan per baris.
- Umum, Tampilan, Tab & navigasi, Musik, Reminder sebagai lima kategori.
- Detail reminder dibuka di panel Reminder; tidak diduplikasi pada menu lain.
- Minimal satu tab aktif dan tab default mengikuti tab yang tersedia.
- Ikon navigasi monokrom; footer Reminder dihapus.
- Penempatan piksel dan clipping notch diperbaiki untuk tepi layar/stage.
- Data relatif terhadap executable, tanpa startup Windows otomatis.
- Fallback software WARP untuk pembuatan renderer.

Batas alpha: media bergantung dukungan pemutar; lirik/jadwal memerlukan layanan online; dataset libur hanya 2026; suara Sholat belum rekaman adzan; timer fokus tidak berlanjut setelah Keluar/restart; aksesibilitas screen reader belum lengkap.
